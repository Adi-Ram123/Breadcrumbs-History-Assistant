5. Diagnostics menu, dark

The dropdown floats on a darker, heavier shadow, because a light shadow disappears on dark. The switch flips the same way as Stop: light track, dark knob.

Dark mode rules for the spec

1

Follows the system

The panel uses prefers-color-scheme, so it matches Chrome and macOS with no setting of its own. Every color comes from the shared variables; components contain no raw color values.

2

Favicons on dark

Real favicons with dark artwork on a transparent background (GitHub, Wikipedia) vanish on #1a1a1a. In dark mode each favicon sits on a 16px light rounded square (#e8e8e8) so every icon stays visible. The placeholder letters in these frames don't show this problem, but real icons will.

3

Same contrast floor

Every text pair stays at 4.5:1 or higher in both themes, and the focus ring uses the lifted blue in dark.
