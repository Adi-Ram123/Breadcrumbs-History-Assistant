# Decision log

One file per episode: `NN-short-name.md` (for example `01-llm-runtime.md`). Pass-bar changes, parser swap results, and every agent episode from the proposal go here. Aditya's open model decisions are listed in `ml/CLAUDE.md` and get recorded here as they are made.

## Template

```markdown
# NN: <title>

- **Date:**
- **Owner:**
- **Request:** what we asked for (agent prompt or question)
- **Commit:** <sha>
- **Acceptance command:** the command that decides pass or fail
- **Observed:** what happened, with numbers
- **Decided:** what we kept, changed or rejected, and why
- **Remaining limitation:**
```
